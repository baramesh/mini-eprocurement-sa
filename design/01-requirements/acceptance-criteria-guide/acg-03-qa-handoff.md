# สิ่งที่ส่งต่อให้ QA และสิ่งที่ยังไม่ครอบคลุม

เกณฑ์ตรวจรับครอบคลุมทุกข้อกำหนดเชิงหน้าที่และทุก API operation แต่ **ไม่ครอบคลุม** ประสิทธิภาพ (NFR-01 ต้องวัดบนข้อมูล 100,000 PR) การทดสอบความมั่นคงปลอดภัยเชิงลึก การทดสอบหน้าจอแบบ end-to-end และข้อมูลทดสอบจริง สิ่งเหล่านี้เป็นหน้าที่ของแผนการทดสอบของ QA เกณฑ์ที่ระบุค่าขอบวงเงิน (5,000 / 20,000 / 200,000 บาท) ใช้ค่าสมมติของโจทย์นี้ ต้องปรับเมื่อใช้เกณฑ์จริง
