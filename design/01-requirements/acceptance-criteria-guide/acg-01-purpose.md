# วัตถุประสงค์

เอกสารนี้รวมเกณฑ์ตรวจรับ (Acceptance Criteria) ที่นักวิเคราะห์ระบบเขียนจากข้อกำหนดเชิงหน้าที่ กฎธุรกิจ และกติกา API เกณฑ์ตรวจรับบอกว่า **เมื่อใดถือว่าข้อกำหนดข้อหนึ่งทำเสร็จและถูกต้อง** ไม่ใช่ขั้นตอนการทดสอบ ทีม QA นำไปออกแบบกรณีทดสอบ (test case) ข้อมูลทดสอบ และแผนการทดสอบต่อเอง
