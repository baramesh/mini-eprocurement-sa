# วิธีอ่านตารางเกณฑ์

แต่ละข้อมีรหัส `AC-NN-MM` โดย NN คือเลขของข้อกำหนดเชิงหน้าที่หลักที่เกณฑ์นั้นตรวจ และ MM คือลำดับในข้อกำหนดนั้น คอลัมน์ชนิดบอกลักษณะ: Positive (ทางปกติ), Negative (ต้องถูกปฏิเสธ), Boundary (ค่าขอบของวงเงินหรือความยาว), Security (สิทธิ์และการแยกหน้าที่), Idempotency และ Resilience (การส่งซ้ำและความล้มเหลวของส่วนประกอบ), Concurrency (การทำงานพร้อมกัน) คอลัมน์สถานการณ์คือเงื่อนไขเริ่มต้นและสิ่งที่ผู้ใช้หรือระบบทำ คอลัมน์ผลที่ต้องเป็นจริงคือสิ่งที่ต้องตรวจพบ รวมรหัส HTTP และรหัสข้อผิดพลาดตามข้อกำหนด API
