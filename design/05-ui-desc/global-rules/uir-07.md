# เมนูและหน้าแรก

เมนูบนสุดแสดงเฉพาะลิงก์ของหน้าที่บทบาทของผู้ใช้เข้าได้ และแสดงอีเมลกับบทบาทของผู้ใช้ปัจจุบัน หน้าแรกคือรายการใบขอซื้อ ผู้ใช้ที่ไม่มีโทเค็นถูกส่งไปหน้ายืนยันตัวตนก่อน แล้วกลับมาที่หน้าที่ขอไว้

| บทบาท | ลิงก์ในเมนู |
|---|---|
| `REQUESTER`, `RECEIVER`, `COMMITTEE`, `DEPT_APPROVER` | ใบขอซื้อ; ผู้อนุมัติ (`DEPT_APPROVER`, `COMMITTEE`) เพิ่ม งานรออนุมัติ |
| `PROCUREMENT` | ใบขอซื้อ, ผู้ขาย |
| `PROCUREMENT_HEAD` | ใบขอซื้อ, งานรออนุมัติ, ผู้ขาย, รายงาน |
| `ADMIN` | ใบขอซื้อ, ผู้ขาย, รายงาน, Audit |
