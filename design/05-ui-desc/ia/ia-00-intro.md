# บทนำ

เอกสารนี้อธิบายโครงสร้างข้อมูลของส่วนติดต่อผู้ใช้ (Information Architecture): กลุ่มผู้ใช้ ผังการนำทาง ทะเบียนหน้าจอ สิทธิ์การเข้าถึงของแต่ละบทบาท ข้อมูลที่แต่ละหน้าจอแสดงและบันทึก ศัพท์ที่ใช้ และกติกากรณีขอบเขต เพื่อให้ทีม UX, UI, Dev และ QA อ้างอิงร่วมกันได้ ส่วนรายละเอียดฟิลด์และรูปแบบการแสดงผลอยู่ในเอกสาร UX/UI
