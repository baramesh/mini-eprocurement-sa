# Wireframe SCR-01 รายการใบขอซื้อ

เลขกำกับในภาพ:

1. ตัวกรองสถานะ ช่วงวันที่ และผู้ขอซื้อ (ผู้ขอซื้อเห็นเฉพาะ PR ของตน)
2. ปุ่มสร้าง PR ไปหน้าแบบฟอร์ม (SCR-02)
3. ตารางรายการ แถวละหนึ่ง PR แสดงสถานะเป็นข้อความ; คลิกแถวเพื่อเปิดรายละเอียด
4. ปุ่มโหลดเพิ่มแบบ keyset ครั้งละ 50 แถว
