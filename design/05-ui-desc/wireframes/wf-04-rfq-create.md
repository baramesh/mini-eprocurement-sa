# Wireframe SCR-04 สร้าง RFQ และเชิญผู้ขาย

เลขกำกับในภาพ:

1. กำหนดปิดรับใบเสนอราคา (หลังกำหนดจะบันทึกใบเสนอราคาไม่ได้ ตาม BR-07)
2. รายการผู้ขาย: เลือกอย่างน้อย 3 ราย ผู้ขายที่ถูกระงับเลือกไม่ได้ (BR-11)
3. สร้าง RFQ ใช้ได้เมื่อเลือกครบ 3 ราย; PR วงเงินไม่เกิน 5,000 บาทจะแจ้งให้ซื้อตรงแทน
