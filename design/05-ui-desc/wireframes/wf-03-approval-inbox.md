# Wireframe SCR-03 กล่องอนุมัติ

เลขกำกับในภาพ:

1. เห็นเฉพาะงานที่ถึงขั้นของบทบาทตน เรียงเก่าสุดก่อน (ชนิด PR และผลเลือกผู้ชนะใช้หน้าเดียวกัน)
2. แถวที่เลือก แสดงขั้นที่และผู้ตัดสินขั้นก่อนหน้า
3. ช่องความเห็น บังคับเมื่อปฏิเสธ (ไม่เกิน 500 ตัวอักษร)
4. อนุมัติหรือปฏิเสธ; ซ่อนปุ่มเมื่อผู้ใช้คือผู้ขอซื้อหรือผู้เสนอผล (BR-04)
