# Wireframe SCR-02 แบบฟอร์มใบขอซื้อ

เลขกำกับในภาพ:

1. หัวข้อ 1–200 ตัวอักษร (บังคับ)
2. เหตุผลความจำเป็น 1–1,000 ตัวอักษร (บังคับ)
3. วันที่ต้องการใช้ แสดง พ.ศ. ต้องไม่ก่อนวันนี้
4. ตารางรายการ: จำนวนมากกว่า 0, หน่วยนับ, ราคาต่อหน่วยตั้งแต่ 0; แถวรวมคำนวณทันที
5. วงเงินรวมและสายอนุมัติตามกฎวงเงิน (BR-03) แสดงก่อนกดส่ง
6. ปุ่มบันทึกร่าง / ส่งอนุมัติ / ยกเลิก ใช้ได้เมื่อสถานะ DRAFT; ปุ่มที่เรียก API ปิดระหว่างรอ
