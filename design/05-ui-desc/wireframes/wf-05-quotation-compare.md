# Wireframe SCR-05 บันทึกและเปรียบเทียบใบเสนอราคา

เลขกำกับในภาพ:

1. ตารางเปรียบเทียบ: แถวคือรายการของ PR คอลัมน์คือผู้ขายที่ได้รับเชิญ มีราคารวมและระยะเวลาส่งมอบ
2. ไฮไลต์ราคารวมต่ำสุด
3. เหตุผลบังคับอย่างน้อย 20 ตัวอักษร (พร้อมตัวนับ) เมื่อเลือกรายที่ไม่ใช่ต่ำสุด (BR-06)
4. เสนอผลเพื่อส่งอนุมัติ (RFQ เป็น AWARD_PENDING) ใช้ได้เมื่อมีใบเสนอราคาอย่างน้อย 2 ราย (BR-02)
