# Wireframe SCR-08 ทะเบียนผู้ขาย

เลขกำกับในภาพ:

1. ค้นหาตามชื่อหรือเลขผู้เสียภาษี และกรองตามสถานะ
2. เพิ่มผู้ขายใหม่
3. ตารางผู้ขาย; ปุ่มระงับ/เปิดใช้เห็นเฉพาะหัวหน้าจัดซื้อ ต้องระบุเหตุผล
4. แบบฟอร์มเพิ่มผู้ขาย: เลขผู้เสียภาษี 13 หลักและไม่ซ้ำ (ERR-VND-001)
