# ความสัมพันธ์กับโครงสร้างข้อมูลของส่วนติดต่อผู้ใช้

โครงสร้างการนำทาง บทบาทกับหน้าจอ บทบาทกับ API operation ข้อมูลที่แต่ละหน้าจอแสดงและบันทึก และกติกา IA (IAR) กำหนดไว้ที่เล่มการออกแบบโครงสร้างข้อมูลของส่วนติดต่อผู้ใช้ หน้าจอทุกหน้าในเล่มนี้ทำตามนั้น และแต่ละหน้าระบุกติกา IA และกติกาของระบบที่ใช้ไว้ในหัวข้อพฤติกรรมของหน้านั้น
