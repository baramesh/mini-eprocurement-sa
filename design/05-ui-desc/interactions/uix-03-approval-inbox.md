# พฤติกรรมหน้า SCR-03 กล่องอนุมัติ

**เส้นทาง:** `/approvals` แสดงเฉพาะขั้นที่ถึงบทบาทของผู้ใช้ (เซิร์ฟเวอร์กรองให้) หน้าไม่แบ่งหน้า เพราะงานค้างต่อบทบาทมีจำนวนน้อย

<!-- table: เหตุการณ์ในหน้า SCR-03 -->
| ตัวกระตุ้น | เงื่อนไข | ผลที่ผู้ใช้เห็น | เรียก API |
|---|---|---|---|
| เปิดหน้า | `DEPT_APPROVER`, `PROCUREMENT_HEAD`, `COMMITTEE` | แสดงรายการ เรียงเก่าสุดก่อน | `listMyApprovals` |
| กดเลขที่เอกสาร | `docType` เป็น `PR` | ไป SCR-02 แบบอ่านอย่างเดียว | ไม่เรียก |
| กดเลขที่เอกสาร | `docType` เป็น `AWARD` | ไป SCR-05 ของ RFQ นั้นเพื่อดูตารางเทียบราคา | ไม่เรียก |
| แสดงปุ่มตัดสิน | `proposerId` ไม่ใช่ผู้ใช้ปัจจุบัน | มีปุ่มอนุมัติและปฏิเสธ | ไม่เรียก |
| ซ่อนปุ่มตัดสิน | `proposerId` เป็นผู้ใช้ปัจจุบัน (BR-04) | แสดงข้อความ "ผู้ขอหรือผู้เสนอผลอนุมัติเองไม่ได้" แทนปุ่ม | ไม่เรียก |
| กดอนุมัติ | แถวที่มีปุ่ม | ปิดปุ่มระหว่างรอ สำเร็จแล้วแถวหายและโหลดรายการใหม่ | `decideApproval` แล้ว `listMyApprovals` |
| กดปฏิเสธ | แถวที่มีปุ่ม | เปิดช่องเหตุผล (บังคับ ไม่เกิน 500 ตัวอักษร) กดยืนยันแล้วจึงส่ง | `decideApproval` แล้ว `listMyApprovals` |

| สถานะ | เมื่อไร | สิ่งที่แสดง |
|---|---|---|
| กำลังโหลด | ระหว่างรอ response | โครงตาราง |
| ว่าง | `[]` | "ไม่มีรายการรออนุมัติ" |
| ปฏิเสธโดยไม่มีเหตุผล | ก่อนเรียก หรือ `422` `ERR-VAL-001` | ข้อความที่ช่องเหตุผล ไม่ปิดช่อง |
| ผู้ขอตัดสินเอง | `403` `ERR-SOD-001` (กรณีหน้าไม่ได้ซ่อนปุ่ม) | แสดงข้อความจาก response และซ่อนปุ่มของแถวนั้น |
| มีผู้อื่นตัดสินไปแล้ว | `409` `ERR-STATE-001` | แจ้ง "ขั้นนี้ถูกตัดสินแล้ว" แล้วโหลดรายการใหม่ |
| token หมดอายุ | `401` `ERR-AUTH-001` | ไปยืนยันตัวตนใหม่ แล้วกลับหน้านี้ |
