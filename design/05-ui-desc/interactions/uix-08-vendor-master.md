# พฤติกรรมหน้า SCR-08 ทะเบียนผู้ขาย

**เส้นทาง:** `/vendors` `PROCUREMENT` เพิ่มผู้ขายได้ `PROCUREMENT_HEAD` ระงับหรือเปิดใช้ได้ `ADMIN` ดูอย่างเดียว ปุ่มที่บทบาทไม่มีสิทธิ์ไม่แสดง

<!-- table: เหตุการณ์ในหน้า SCR-08 -->
| ตัวกระตุ้น | เงื่อนไข | ผลที่ผู้ใช้เห็น | เรียก API |
|---|---|---|---|
| เปิดหน้า | บทบาทที่เข้าได้ | แสดงรายการผู้ขายทั้งหมด | `listVendors` |
| พิมพ์ค้นหา | หยุดพิมพ์ 300 ms | กรองรายการตามชื่อหรือรหัส | `listVendors` |
| เปลี่ยนตัวกรองสถานะ | ค่าเปลี่ยน | โหลดรายการใหม่ | `listVendors` |
| กดเพิ่มผู้ขาย | `PROCUREMENT` | เปิดแบบกรอกชื่อ เลขผู้เสียภาษี 13 หลัก อีเมล (ไม่บังคับ) | ไม่เรียก |
| กดบันทึก | ฟอร์มผ่านการตรวจ | ปิดปุ่มระหว่างรอ สำเร็จแล้วเพิ่มแถว | `createVendor` |
| กดระงับหรือเปิดใช้ | `PROCUREMENT_HEAD` | ถามยืนยันและเหตุผล (บังคับเมื่อระงับ ไม่บังคับเมื่อเปิดใช้) แล้วเปลี่ยนป้าย; ผู้ขายที่ระงับแล้วเชิญหรือออก PO ไม่ได้ (BR-11) | `setVendorStatus` |
