# ข้อมูลตั้งต้น (seed data)

ข้อมูลที่ต้องมีก่อนระบบเริ่มใช้งานได้ ไม่ใช่ข้อมูลธุรกิจที่เกิดจากการใช้งาน ได้แก่ หน่วยงานตั้งต้นและผู้ดูแลระบบหนึ่งราย เก็บเป็นไฟล์ CSV หนึ่งไฟล์ต่อหนึ่งตาราง ชื่อไฟล์ตรงกับชื่อตารางใน schema และโหลดก่อนข้อมูลตัวอย่างเสมอ

บทบาท (`role_code`) เป็นข้อจำกัดของตาราง `app_user` ไม่ใช่ตารางแยก จึงไม่มีไฟล์ตั้งต้นของบทบาท ตัวนับเลขเอกสาร (`doc_sequence`) ถูกสร้างเองเมื่อออกเลขครั้งแรก จึงไม่ตั้งต้นด้วยมือ เกณฑ์วงเงิน (5,000 / 20,000 / 200,000 บาท) อยู่ในกฎธุรกิจและตรรกะของ service ไม่ได้เก็บเป็นข้อมูลในฐานข้อมูล

รายการที่จงใจไม่ใส่ในข้อมูลตั้งต้น: ผู้ใช้งานจริง ผู้ขาย และเอกสารทุกชนิด เพราะเป็นข้อมูลที่เกิดขณะใช้งาน
