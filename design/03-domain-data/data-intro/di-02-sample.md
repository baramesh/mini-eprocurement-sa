# ข้อมูลตัวอย่าง (sample data)

ข้อมูลสมมติชุดเดียวที่เดินผ่านทุกเส้นทางของกระบวนการ เพื่อให้ผู้ออกแบบหน้าจอ ผู้พัฒนา และ QA มีข้อมูลที่เข้าใจตรงกัน ชื่อบุคคล ผู้ขาย เลขผู้เสียภาษี และอีเมลเป็นข้อมูลสมมติทั้งหมด (อีเมลลงท้าย `.example.test`) ไม่ใช่ข้อมูลของบุคคลหรือหน่วยงานจริง

ชุดนี้ครอบคลุม: ซื้อตรงวงเงินต่ำ, RFQ ที่เลือกราคาต่ำสุด, RFQ ที่เลือกผู้ที่ไม่ใช่ราคาต่ำสุดพร้อมเหตุผล, ใบเสนอราคาที่ถูกแทนที่ด้วยฉบับใหม่, สายอนุมัติหนึ่ง สอง และสามขั้น, PR ที่รออนุมัติ, PR ที่ถูกปฏิเสธ, PR ฉบับร่าง, ผู้ขายที่ถูกระงับ, การรับของบางส่วนพร้อมของที่ถูกปฏิเสธ และการรับของครบ

ชุดนี้ไม่ได้ตั้งใจให้ตรงกับค่าในเกณฑ์ตรวจรับรายข้อ เกณฑ์ตรวจรับเป็นผู้กำหนดข้อมูลทดสอบเฉพาะของตน QA ใช้ชุดนี้เป็นฐานตั้งต้นได้ ความสอดคล้องภายในของข้อมูลตรวจด้วยชุดตรวจ (`sql/data-checks.sql`) ที่รันหลังโหลดบน SQL Server จริง
