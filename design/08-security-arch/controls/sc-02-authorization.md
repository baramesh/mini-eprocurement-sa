# การให้สิทธิ์

ตรวจสองชั้น: บทบาทต้องอยู่ใน `x-roles` ของ operation แล้วตรวจขอบเขตข้อมูลตามหน่วยงานและเจ้าของเอกสารใน service ไม่ผ่านตอบ `ERR-AUTH-002` กฎแยกหน้าที่ (ห้ามอนุมัติของตนเอง) ตรวจที่โมดูลอนุมัติและตอบ `ERR-SOD-001` การซ่อนปุ่มที่หน้าจอเป็นเพียงความสะดวกของผู้ใช้ ไม่ใช่มาตรการความปลอดภัย
