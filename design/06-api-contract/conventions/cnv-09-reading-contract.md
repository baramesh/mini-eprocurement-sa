# การอ่านข้อกำหนดของ operation

แต่ละ operation มีตารางข้อมูลทั่วไป พารามิเตอร์ request body response ทุกรหัส HTTP และตัวอย่าง คอลัมน์ "ที่มา" ของฟิลด์ระบุตาราง.คอลัมน์ในฐานข้อมูลที่ค่านั้นมาจาก (เช่น `purchase_request.pr_no`) หรือเส้นทางข้ามตาราง (เช่น `app_user[user_id=requester_id].full_name` คือชื่อผู้ใช้ที่ `user_id` ตรงกับ `requester_id` ของแถวที่ถืออยู่) ค่าที่ไม่ได้อยู่ในคอลัมน์ใดระบุวิธีคำนวณแทน ตัวอย่าง request และ response ในไฟล์ `api/examples/` สร้างจากแถวของข้อมูลตัวอย่างผ่านการแมปเดียวกัน จึงตรงกับ `sample-data` และตรวจกับ schema ของ response ทุกครั้งที่สร้างเอกสาร หน้าจอที่เรียก operation และการ์ดเจ้าของระบุไว้ในตารางข้อมูลทั่วไป
