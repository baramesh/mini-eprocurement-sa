# คำศัพท์ของ audit trail

`audit_log` รับเฉพาะ INSERT ทุก operation ที่เปลี่ยนข้อมูลเขียนหนึ่งแถวต่อเหตุการณ์ในธุรกรรมเดียวกัน ค่า `entity` และ `action` มีชุดคงที่ตามตาราง และ `listAuditLogs` ค้นด้วยคู่ `entity` กับ `entityId` (เอกสารแต่ละชนิดมีประวัติของตนเอง การสร้าง RFQ จึงอยู่ใน `entity` เป็น `RFQ` ไม่ปนในประวัติของ PR)

| entity | action | เกิดเมื่อ | `detail` |
|---|---|---|---|
| `PR` | `CREATE`, `UPDATE` | สร้างและแก้ใบขอซื้อฉบับร่าง | ว่าง |
| `PR` | `SUBMIT` | ส่งอนุมัติ | `ส่งอนุมัติ` |
| `PR` | `APPROVE`, `REJECT` | ผู้อนุมัติตัดสินขั้นของ PR | ความเห็น หรือ `ขั้น N` เมื่อไม่มีความเห็น |
| `RFQ` | `CREATE` | สร้าง RFQ | ว่าง |
| `RFQ` | `AWARD` | เสนอผลเลือกผู้ชนะ | เหตุผลที่ไม่เลือกราคาต่ำสุด (ถ้ามี) |
| `RFQ` | `APPROVE`, `REJECT` | ผู้อนุมัติตัดสินผลเลือกผู้ชนะ | ความเห็น หรือ `ขั้น N` |
| `PO` | `CREATE`, `ISSUE`, `RECEIVE` | สร้าง ออก PO และบันทึกรับของ | ว่าง |
| `VENDOR` | `CREATE`, `STATUS` | สร้างผู้ขาย และเปลี่ยนสถานะ | เหตุผลของการเปลี่ยนสถานะ |
