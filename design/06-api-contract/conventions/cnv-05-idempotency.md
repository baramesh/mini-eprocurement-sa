# การเรียกซ้ำ

คำสั่งที่เปลี่ยนสถานะรับ `Idempotency-Key` (UUID) ซึ่งบังคับส่ง; เก็บผลที่สำเร็จไว้ 24 ชั่วโมง แยกตามผู้เรียก; ส่งซ้ำด้วย payload เดิมได้ผลเดิมโดยไม่ทำซ้ำ; payload ต่างจากเดิมตอบ 422 `ERR-IDEM-001`; ไม่ส่งหัวนี้ตอบ 422 `ERR-VAL-001` ที่ field `Idempotency-Key`; ผลที่เป็นข้อผิดพลาดไม่ถูกเก็บ ส่งซ้ำจึงตรวจใหม่ทุกครั้ง
