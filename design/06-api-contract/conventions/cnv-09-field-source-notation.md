# รูปแบบการเขียนที่มาของฟิลด์

คอลัมน์ "ที่มา" ของฟิลด์ระบุตาราง.คอลัมน์ในฐานข้อมูลที่ค่านั้นมาจากหรือถูกเก็บลง เช่น `purchase_request.pr_no` หรือเส้นทางข้ามตาราง เช่น `app_user[user_id=requester_id].full_name` คือชื่อผู้ใช้ที่ `user_id` ตรงกับ `requester_id` ของแถวที่ถืออยู่ ค่าที่ไม่ได้อยู่ในคอลัมน์ใดระบุวิธีคำนวณแทน
