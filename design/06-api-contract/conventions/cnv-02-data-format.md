# รูปแบบข้อมูล

JSON, UTF-8; วันที่เวลา (`date-time`) เป็น ISO 8601 UTC; เงินเป็นตัวเลขทศนิยม 2 ตำแหน่ง หน่วยบาท

- **การปัดเศษเงิน**: ปัดครึ่งขึ้น (half-up) เป็นทศนิยม 2 ตำแหน่ง คำนวณด้วยชนิดทศนิยมฐานสิบ (`DECIMAL(18,2)` ในฐานข้อมูล ชนิด decimal ในโค้ด) ห้ามใช้ floating point; ปัดทีละบรรทัดแล้วจึงรวม
- **วันที่ (`date`)** ในพารามิเตอร์และฟิลด์ เช่น `neededByDate`, `createdFrom`, `createdTo`, `from`, `to` คือวันตามปฏิทิน Asia/Bangkok (UTC+7) ส่วนฟิลด์ `date-time` เก็บและส่งเป็น UTC; ช่วงวันที่นับตั้งแต่ 00:00 ของวันแรกถึง 23:59:59 ของวันสุดท้ายตามเวลา Asia/Bangkok
- **การนับ "ตัวอักษร"** ของข้อความ (เช่น `reason` ขั้นต่ำ 20 และความยาวสูงสุดของฟิลด์) นับเป็น Unicode code point หลัง normalize เป็น NFC โดยนับสระและวรรณยุกต์ภาษาไทยเป็นตัวอักษรหนึ่งตัวต่อ code point
