# โปรไฟล์ทดสอบ

เพื่อให้ทีมเขียน test อัตโนมัติ (API test, E2E) ได้โดยไม่ต้องพึ่ง SSO จริงหรือรอเวลาจริง API มีโปรไฟล์ `test` ที่เปิดด้วยตัวแปรสภาพแวดล้อม `APP_PROFILE=test` เท่านั้น ห้ามเปิดในสภาพแวดล้อมจริง และสิ่งที่อยู่ในตารางนี้ไม่อยู่ใน OpenAPI สาธารณะ

| สิ่งที่ต้องใช้ | โปรไฟล์ทดสอบ |
|---|---|
| token | JWT ลายเซ็น HS256 ด้วยคีย์ในตัวแปร `TEST_JWT_SECRET` มี claim ตาม CNV-03 |
| ผู้ใช้ทดสอบ | แถว `app_user` ใน `sample-data` (หนึ่งบทบาทต่อหนึ่งคน และหน่วยงานฝั่งปฏิบัติการอีกชุดหนึ่ง) ใช้ `email` ของแถวเหล่านั้นใน claim |
| ล้างข้อมูล | `POST /__test/reset` (บทบาท `ADMIN`) โหลด `sample-data` กลับสู่สภาพเริ่มต้นและรีเซ็ตตัวนับเลขที่เอกสาร |
| ล้างแคช Idempotency | `POST /__test/flush-idempotency` (บทบาท `ADMIN`) ใช้ทดสอบกรณีแคชหายแล้วส่งซ้ำ |
| ควบคุมเวลา | หัว `X-Test-Now` (ISO 8601 UTC) ทำให้ API ใช้ค่านั้นแทนเวลาปัจจุบันในคำขอนั้น ใช้ทดสอบกำหนดส่งใบเสนอราคาโดยไม่ต้องรอ |
