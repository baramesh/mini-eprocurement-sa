# รูปแบบข้อผิดพลาด

```json
{
  "code": "ERR-RFQ-001",
  "message": "ต้องเชิญผู้ขายอย่างน้อย 3 ราย",
  "details": [{ "field": "vendorIds", "issue": "minItems: 3" }]
}
```

`message` เป็นข้อความภาษาไทยสำหรับผู้ใช้ และหน้าจอแสดงข้อความนี้ที่ทุกฟิลด์ที่ปรากฏใน `details[].field`; `details[].issue` เป็นข้อความเทคนิคภาษาอังกฤษสำหรับนักพัฒนา ไม่แสดงต่อผู้ใช้
