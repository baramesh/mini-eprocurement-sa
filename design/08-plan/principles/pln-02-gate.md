# กติกา gate ของ Journey

Journey หนึ่งจะขึ้น Sprint ได้เมื่อ (1) ทุกหน้าจอของ Journey มีเจ้าของการ์ด (2) การ์ดหน้าจอทุกใบจบใน Sprint เดียว (3) การ์ดไม่ขึ้นกับการ์ดที่วางไว้ใน Sprint หลังกว่า และ (4) การ์ดทุกใบผ่านการตรวจรับเป็นสถานะ `ready` ข้อ 1 ถึง 3 สคริปต์ตรวจให้ ข้อ 4 ต้องเป็นการตัดสินของทีม ตราบที่การ์ดยังเป็น `draft` verdict จึงเป็น `REFINING`
