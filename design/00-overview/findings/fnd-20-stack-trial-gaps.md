what: 'เอา reference server ไปรันบน stack ตาม ADR-01 จริง (ASP.NET Core 8, SQL Server 2022, Redis, nginx บน OrbStack) แล้วรันชุดทดสอบเดิมกับฐานข้อมูลจริง พบสิ่งที่ server แบบหน่วยความจำมองไม่เห็น: ข้อมูลทดสอบที่ใช้ราคา 3 ทศนิยมผ่านใน server เดิมแต่ฐานข้อมูลเก็บได้ 2 ตำแหน่ง จึงต้องกำหนดความแม่นยำและช่วงค่าของเงิน, ขั้นตอนออกเลขที่เอกสารถ้าเรียกในธุรกรรมธุรกิจจะย้อนเลขที่พร้อมธุรกรรมซึ่งขัดกับ V-08, ชื่อฟิลด์ lineNo ชนคำสงวน LINENO ของ T-SQL, ไลบรารีเชื่อม SQL Server ใช้ไม่ได้กับโหมด invariant globalization, ดัชนีเฉพาะที่ชนกันตอนมีคำขอพร้อมกันตกเป็น 500 หรือรหัสข้อผิดพลาดผิด (taxId ซ้ำต้องเป็น ERR-VND-001) และไม่มีเอกสารบอกวิธีรันชุดนี้'
fix: 'เพิ่ม DEV-03 (ส่วนประกอบ วิธีรัน และข้อจำกัดของ stack); กำหนดความแม่นยำและช่วงค่าใน CNV-02 และ V-08; ระบุใน V-08 ว่าเรียกขั้นตอนออกเลขที่นอกธุรกรรมธุรกิจ; ระบุใน V-09 ว่าผู้แพ้การแข่งกันบันทึกใบเสนอราคาได้ 409. เพิ่มการทดสอบระดับฐานข้อมูลและคำขอพร้อมกัน 7 ข้อ (สิทธิ์ของบัญชีแอปกับ audit_log, ใบเสนอราคาเก่ายังอยู่ที่ is_active เป็น 0, รับของพร้อมกันเกินจำนวนสั่ง, ผู้ขายซ้ำพร้อมกัน, ส่ง PR พร้อมกัน, เสนอราคาพร้อมกัน, ราคา 3 ทศนิยม)'
