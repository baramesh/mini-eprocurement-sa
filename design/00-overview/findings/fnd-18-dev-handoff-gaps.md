what: 'ผู้ตรวจอ่านชุดเอกสารด้วยมุมมองนักพัฒนาแล้วพบว่าส่งต่อไม่ได้: หน้าจอไม่บอกว่าเรียก API ไหนตอนไหนและใช้ฟิลด์ใด, API ไม่มีตัวอย่างและไม่บอกว่าแต่ละฟิลด์มาจากตารางไหน, runtime view มีแค่สองชิ้น และไม่มี error 401/403/404 ใน OpenAPI เมื่อผูกหน้าจอกับ API รายฟิลด์ยังพบว่า API ขาด operation อ่าน RFQ และ PO ที่หน้าเปรียบเทียบและหน้ารับของต้องใช้ และ response ของกล่องอนุมัติไม่มีเลขที่เอกสาร ชื่อผู้ขอ และวงเงินที่หน้าต้องแสดง ทั้งที่ตัวตรวจเดิมผ่านหมด เพราะตรวจแค่ว่ารหัสที่อ้างมีอยู่จริง ไม่ได้ตรวจว่าข้อมูลที่หน้าจอต้องใช้มีใน response'
fix: 'เพิ่ม interaction spec ต่อหน้าจอ (เหตุการณ์ → operation → ฟิลด์ที่ส่งและอ่าน) ให้ตัวตรวจเทียบกับ OpenAPI ทีละฟิลด์; ใส่ที่มาของทุกฟิลด์ใน OpenAPI (ตาราง.คอลัมน์ หรือสูตร) และสร้างตัวอย่าง request/response จากข้อมูลตัวอย่างผ่านที่มาเดียวกัน แล้วตรวจกับ schema; เพิ่ม runtime view ให้ทุก operation มี (ตัวตรวจฟ้องถ้าขาด) และ development view; เติม error มาตรฐานทุก operation; เพิ่ม operation getRfq และ getPurchaseOrder พร้อมเกณฑ์ตรวจรับและการ์ด และเติมฟิลด์ใน response ที่หน้าจอต้องใช้. ยังเปิดอยู่: สถานะ CANCELLED ของ PR ไม่มี operation รองรับ และเกณฑ์สายอนุมัติที่หน้าฟอร์มแสดงล่วงหน้ายังไม่มี endpoint ให้อ่าน'
