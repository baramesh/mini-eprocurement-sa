unchecked: reference server เป็นหน่วยความจำ ไม่ใช่ SQL Server จึงยังไม่ได้ทดสอบธุรกรรม การล็อกแถว ดัชนีเฉพาะ และการสร้างเลขที่เอกสารพร้อมกันบนฐานข้อมูลจริง (AC-13-02 และครึ่งหลังของ AC-06-03 เป็นการตรวจชั้นฐานข้อมูล); ไม่ได้ทดสอบหน้าจอ (ไม่มี E2E); ผู้เขียนเอกสาร ผู้เขียน server และผู้เขียนทดสอบเป็น AI ตัวเดียวกัน ไม่ใช่ทีมพัฒนาอิสระ จึงอาจมองไม่เห็นช่องว่างที่คนอื่นจะเจอ; การตัดสินใจที่เติมลงเอกสารรอบนี้ (404 นอกขอบเขต ปัดครึ่งขึ้น เขตเวลา Asia/Bangkok ลบแถวอนุมัติเมื่อปฏิเสธ) ยังไม่ได้ยืนยันกับเจ้าของโจทย์

# รายการตรวจ 9

ชุดทดสอบ API ด้วย Playwright เขียนจากเอกสารที่ส่งต่อ 72 ข้อ: เกณฑ์ตรวจรับครบ 55 ข้อที่ตรวจผ่าน API ได้ (ข้อที่ 56 เป็นการตรวจฐานข้อมูล) กฎใน runtime view และ convention ที่เกณฑ์ไม่ครอบคลุม 16 ข้อ และตรวจว่า response ทุกตัวที่เห็นตรงกับ OpenAPI ผ่านทั้งหมดกับ reference server และทดลองแก้ server ให้ผิดสี่แบบ (ขอบวงเงิน 20,000.00 ข้ามการแยกหน้าที่ นับของที่ปฏิเสธเป็นรับ ลดขั้นต่ำเหตุผล) ทดสอบจับได้ทุกแบบ
