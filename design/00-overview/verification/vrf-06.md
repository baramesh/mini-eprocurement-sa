# รายการตรวจ 6

ความสอดคล้องของเนื้อหาสถาปัตยกรรมและ IA กับเอกสารอื่นถูกตรวจด้วยสคริปต์: ทุก API operation อยู่ในโมดูลเดียว ทุก NFR มีมาตรการ บทบาทของหน้าจอไม่เกินที่ API อนุญาต และทดสอบเชิงลบ 4 แบบจับได้ทุกแบบ
