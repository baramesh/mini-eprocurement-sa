# รายการตรวจ 8

ตัวอย่าง request และ response ทุก operation สร้างจากข้อมูลตัวอย่างและผ่านการตรวจกับ schema ของ response ทุกฟิลด์ใน schema มีที่มา ทุกหน้าจอมี interaction spec ที่ฟิลด์ซึ่งอ่านและส่งมีอยู่จริงใน OpenAPI และทุก operation มี runtime view (ทดสอบเชิงลบ 4 แบบ ตัวตรวจจับได้ทุกแบบ)
