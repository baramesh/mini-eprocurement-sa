# เครื่องมือและสิ่งที่ไม่เผยแพร่

เครื่องมือ AI ที่ใช้คือ Claude Code (Claude Sonnet 5.5) สำหรับร่าง แก้ข้ามไฟล์ รันสคริปต์ และดูภาพหน้าเอกสารที่สร้างจริงเพื่อหาข้อบกพร่องด้านการจัดหน้า; FigCraft (figcraft-cli v0.15.0) สำหรับสร้างและ render wireframe สคริปต์ที่ประกอบเอกสารและตรวจความสอดคล้อง รวมถึงไฟล์คำสั่งประจำโปรเจกต์ของ agent เก็บไว้ในเครื่องผู้จัดทำ ไม่ได้อยู่ใน repository นี้ repository จึงแสดงผลงานและหลักฐาน ไม่ใช่ชุดตั้งค่าที่ใช้รันซ้ำ
