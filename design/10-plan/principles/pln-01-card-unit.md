# หน่วยของการ์ด

การ์ดหนึ่งใบต่อหนึ่งหน้าจอ งาน UI การเรียก API และการทดสอบของหน้าจอเดียวกันเป็นงานย่อยใต้การ์ดเดียว งานที่ไม่มีหน้าจอและใช้ร่วมกันหลายหน้าจอ (ฐานข้อมูล โครงพื้นฐานของ API สายอนุมัติ) เป็นการ์ดสนับสนุนที่ต้องเสร็จก่อนหรือใน Sprint เดียวกับ Journey ที่ใช้ API operation แต่ละตัวมีเจ้าของการ์ดเพียงใบเดียว
