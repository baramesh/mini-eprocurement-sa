# ธุรกรรมและ audit trail

หนึ่ง operation ที่เปลี่ยนข้อมูลคือหนึ่งธุรกรรม และเขียน `audit_log` ในธุรกรรมเดียวกัน ตารางนี้รับเฉพาะ INSERT บัญชีของแอปแก้หรือลบไม่ได้ ประวัติของการปฏิเสธอยู่ที่ `audit_log` ไม่เก็บแถวอนุมัติเก่า
