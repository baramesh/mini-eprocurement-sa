# การสร้างและรันบนเครื่องนักพัฒนา

ชุดอ้างอิง (`reference/`) สร้างตาม ADR-01 และรันด้วย `docker compose up -d --build` ในโฟลเดอร์นั้น ได้ปลายทาง `http://localhost:8080/api/v1` ผ่าน reverse proxy ชุดทดสอบ API (`tests/api-trial`) ยิงที่ปลายทางนี้ ตารางนี้รวมข้อจำกัดของ stack ที่เจอตอนรันจริง ซึ่งเอกสารส่วนอื่นไม่ได้บอก

<!-- table: ส่วนประกอบของชุดรันบนเครื่องนักพัฒนา -->
| ส่วนประกอบ | ภาพ | หน้าที่และข้อควรรู้ |
|---|---|---|
| ฐานข้อมูล | SQL Server 2022 | สร้างจาก `sql/schema.sql` และ `sql/seed-data.sql` โดยงานครั้งเดียวที่รันก่อน API; บนเครื่อง Apple silicon ต้องรันภาพ `linux/amd64` ผ่านการจำลอง |
| บัญชีแอป | `app` | อ่านเขียนข้อมูลและรันขั้นตอนที่เก็บไว้ได้ แต่แก้หรือลบ `audit_log` ไม่ได้ (schema สั่ง DENY ให้ PUBLIC) API ต้องเชื่อมด้วยบัญชีนี้ ไม่ใช่ `sa` |
| แคช | Redis 7 | เก็บผลของ `Idempotency-Key` 24 ชั่วโมง |
| API | ASP.NET Core 8 | อ่านค่าตั้งต้นจากตัวแปรสภาพแวดล้อม; เปิดโปรไฟล์ทดสอบด้วย `APP_PROFILE=test` ห้ามเปิดในสภาพแวดล้อมจริง |
| reverse proxy | nginx | พอร์ตเดียวที่เปิดออก ส่ง `/api/` ต่อให้ API |

<!-- table: ข้อจำกัดของ stack ที่ต้องรู้ก่อนเขียนโค้ด -->
| เรื่อง | ข้อกำหนด |
|---|---|
| ไลบรารีเชื่อม SQL Server | ต้องมี ICU ในภาพ ห้ามเปิดโหมด invariant globalization ไม่เช่นนั้นเปิดการเชื่อมต่อไม่ได้ |
| ชื่อคอลัมน์ผลลัพธ์ | `LINENO` เป็นคำสงวนของ T-SQL ฟิลด์ `lineNo` ของ API ต้องตั้งเป็นชื่อในวงเล็บเหลี่ยมเมื่อใช้เป็นชื่อแทนคอลัมน์ |
| เลขที่เอกสาร | เรียก `usp_next_doc_no` นอกธุรกรรมธุรกิจ (ดู V-08 ขั้น 2) |
| ข้อผิดพลาดจากดัชนีเฉพาะ | ตัวตัดสินสุดท้ายเมื่อมีคำขอพร้อมกัน; ต้องแปลงเป็นรหัสข้อผิดพลาดของ API ตามที่ runtime view ระบุ (เช่น `taxId` ซ้ำเป็น `ERR-VND-001`) ไม่ปล่อยเป็น `500` |
| เวลา | เก็บ `DATETIME2(0)` เป็น UTC ละเอียดระดับวินาที เวลาที่ใส่ในแถวมาจากนาฬิกาของคำขอ (ควบคุมได้ด้วย `X-Test-Now` ในโปรไฟล์ทดสอบ) ไม่ใช้ค่าเริ่มต้นของฐานข้อมูล |
