# API แบบไม่เก็บสถานะ

**บริบท:** ต้องรันหลายชุดหลัง proxy ตามมุมมองการติดตั้ง

**การตัดสินใจ:** API ไม่เก็บ session ในหน่วยความจำ สถานะทั้งหมดอยู่ในฐานข้อมูลหรือแคช

**ผลที่ตามมา:** เพิ่มจำนวนชุดได้โดยไม่มีผลต่อผู้ใช้ แต่ทุกคำขอต้องตรวจ token ใหม่
