# endpoint อนุมัติกลาง

**บริบท:** การอนุมัติ PR และผลเลือกผู้ชนะมีกฎร่วมกัน (สายอนุมัติ, แยกหน้าที่, บันทึกผล)

**การตัดสินใจ:** ใช้ `/approvals/{id}/decision` เดียว แยกชนิดงานด้วย `docType` แทน endpoint แยกต่อเอกสาร

**ผลที่ตามมา:** กฎอยู่ที่เดียว เพิ่มชนิดงานใหม่ไม่ต้องเพิ่ม endpoint แต่ `approval` ไม่มี foreign key ไปเอกสารต้นทาง ต้องบังคับด้วยตรรกะและ unique constraint
