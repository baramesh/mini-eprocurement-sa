# การยืนยันตัวตน

**บริบท:** องค์กรมี SSO กลางอยู่แล้ว ระบบไม่ควรเก็บรหัสผ่าน

**การตัดสินใจ:** ใช้ OpenID Connect กับ SSO ขององค์กร รับ JWT ที่มีรหัสผู้ใช้และบทบาท และให้ API ตรวจลายเซ็นและวันหมดอายุทุกคำขอ

**ผลที่ตามมา:** ไม่ต้องจัดการรหัสผ่านและการลืมรหัส แต่ผูกกับความพร้อมของ SSO และต้องตกลงรูปแบบ claim ของบทบาทกับผู้ดูแล SSO ก่อนพัฒนา
