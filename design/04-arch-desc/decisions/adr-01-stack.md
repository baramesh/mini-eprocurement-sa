# เทคโนโลยีหลัก

**บริบท:** ต้องเลือกภาษาและฐานข้อมูลให้เข้ากับ schema T-SQL ที่ออกแบบไว้ (ROWVERSION, ขั้นตอนออกเลข, ดัชนีแบบมีเงื่อนไข)

**การตัดสินใจ:** ใช้ ASP.NET Core (.NET 8) ฝั่ง API, React และ TypeScript ฝั่งหน้าจอ และ SQL Server 2022

**ผลที่ตามมา:** ใช้ฟีเจอร์ของ SQL Server ได้เต็ม แต่ผูกกับผู้ขายฐานข้อมูลรายเดียว ทางเลือกอื่นที่ไม่ได้เลือกคือ Node.js หรือ Java กับ PostgreSQL ซึ่งต้องออกแบบ schema ใหม่
