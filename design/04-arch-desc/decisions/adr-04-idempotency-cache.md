# ที่เก็บ Idempotency-Key

**บริบท:** ต้องเก็บผลของคำสั่ง 24 ชั่วโมง แต่ไม่ต้องการเพิ่มตารางในฐานข้อมูลหลัก

**การตัดสินใจ:** เก็บใน Redis พร้อม TTL ไม่เพิ่มตารางใน SQL Server

**ผลที่ตามมา:** เร็วและหมดอายุเอง แต่ถ้าแคชหาย การส่งซ้ำอาจทำงานซ้ำ จึงต้องมีกฎสถานะของเอกสารเป็นด่านที่สอง (`ERR-STATE-001`) และต้องทดสอบกรณีนี้
